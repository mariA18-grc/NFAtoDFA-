Lenguajes Formales · Aho et al., secciones 4.4 a 5.2

1 La gramática

Escribe una producción por línea. Usa -> para la flecha, espacios o | para separar alternativas y e para épsilon. El símbolo inicial es S.

2 Analizar una cadena

LL(1) = análisis descendente (sección 4.4). SLR(1) = análisis ascendente (secciones 4.5 y 4.6). Usa e para la cadena vacía.

3 Definición Dirigida por la Sintaxis

Calcula un puntaje: suma de (peso × posición) de cada color, con r=1, g=2, b=3. Por ejemplo r,g,b = 1×1 + 2×2 + 3×3 = 14. Muestra el árbol anotado, el grafo de dependencias y el orden de evaluación (secciones 5.1 y 5.2).
